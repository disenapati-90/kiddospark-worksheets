Coding-Decoding Worksheet 2

Think carefully and circle the answer.

Name: ________________Date: ___________Score: ____ / 10
  1. If CHAIR is written as RIAHC (letters reversed), how is CHAIR's friend TABLE written backward?
    A) ELBATB) ELBTAC) TABLED) EBLAT
  2. If A=1, B=2 ... Z=26, what is the code for TEN using its first letter T?
    A) 20B) 19C) 21D) 18
  3. If MOON is written as NPPO (each letter +1), how is STAR written?
    A) TUBSB) TUBTC) SUBSD) TVBS
  4. In a code, 5 means 'Go', 3 means 'Stop', 7 means 'Wait'. What does 5-3-7 mean?
    A) Go Stop WaitB) Stop Go WaitC) Wait Stop GoD) Go Wait Stop
  5. If FISH is written as EHRG (each letter -1), how is BIRD written?
    A) AHQCB) AHQDC) AGQCD) BHQC
  6. In a code, 2 means 'Red' and 4 means 'Blue'. The code '24' means 'Red Blue'. What does '42' mean?
    A) Blue RedB) Red BlueC) Blue BlueD) Red Red
  7. If TREE is coded as USFF (each letter +1), how is LEAF coded?
    A) MFBGB) MFBHC) LFBGD) MFAG
  8. If PIG is written as QJH (each letter +1), what word does QJH decode back to?
    A) PIGB) PIHC) PJGD) OIG
  9. If A=26, B=25, C=24 ... (reverse order), what number is C?
    A) 24B) 23C) 25D) 3
  10. If MILK is written as NJML (each letter +1), how is CAKE written?
    A) DBLFB) DBLGC) DBKFD) CBLF

Answer key

  1. A) ELBAT
  2. A) 20
  3. A) TUBS
  4. A) Go Stop Wait
  5. A) AHQC
  6. A) Blue Red
  7. A) MFBG
  8. A) PIG
  9. A) 24
  10. A) DBLF
