Coding-Decoding Worksheet 3

Think carefully and circle the answer.

Name: ________________Date: ___________Score: ____ / 10
  1. If BOOK is written as YLLH (each letter moved back 3 steps), how is DOOR written?
    A) ALLOB) ALLPC) BLLOD) ALMO
  2. If each letter is replaced by the letter 2 places after it, CAT becomes ECV. Using the same code, how is DOG written?
    A) FQIB) FPIC) FQJD) EQI
  3. In a code, each letter's value is its position doubled (A=2, B=4, C=6...). What is the code for E?
    A) 10B) 8C) 12D) 6
  4. If ROSE is called LILY, and LILY is called LOTUS, what flower do people really mean when they say 'LOTUS'?
    A) RoseB) LilyC) LotusD) Jasmine
  5. In a code, every vowel in a word is replaced by the next vowel (A→E, E→I, I→O, O→U, U→A). How is CAT coded?
    A) CETB) CITC) COTD) CUT
  6. If MONDAY is coded as NPOEBZ (each letter +1), which day is coded as UVFTEBZ?
    A) TUESDAYB) MONDAYC) SUNDAYD) SATURDAY
  7. If every digit is replaced by (9 − digit), what does 1234 become?
    A) 8765B) 7865C) 8766D) 8756
  8. If each letter is swapped with its opposite in the alphabet (A↔Z, B↔Y, C↔X...), how is CAB coded?
    A) XZYB) ZXYC) XYZD) YZX
  9. If a word is first reversed, then each letter shifted +1, how is CAT coded? (CAT → TAC → shift +1)
    A) UBDB) DBUC) TACD) DAB
  10. If RED is called GREEN, and GREEN is called BLUE, what do people call the actual color of grass (green)?
    A) RedB) GreenC) BlueD) Yellow

Answer key

  1. A) ALLO
  2. A) FQI
  3. A) 10
  4. B) Lily
  5. A) CET
  6. A) TUESDAY
  7. A) 8765
  8. A) XZY
  9. A) UBD
  10. C) Blue
