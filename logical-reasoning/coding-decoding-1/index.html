Coding-Decoding Worksheet 1

Think carefully and circle the answer.

Name: ________________Date: ___________Score: ____ / 10
  1. If CAT is coded as DBU (each letter moved 1 step forward), how is DOG coded?
    A) EPHB) EPGC) DPHD) DPG
  2. In a code, 1=🐱 and 2=🐶. What does the code '1 2' mean?
    A) 🐱🐶B) 🐶🐱C) 🐱🐱D) 🐶🐶
  3. If B is coded as C, and C is coded as D, how is A coded?
    A) BB) ZC) CD) D
  4. If A=1, B=2, C=3 ... what number stands for E?
    A) 5B) 4C) 6D) 3
  5. If SUN is coded as TVO (each letter +1), how is FUN coded?
    A) GVOB) GVNC) FVOD) GWO
  6. In a code, 🔴 means RED and 🔵 means BLUE. What does 🔴🔵 mean?
    A) RED BLUEB) BLUE REDC) RED REDD) BLUE BLUE
  7. If 1=A, 2=B, 3=C, what word does 3-1-3 spell?
    A) CACB) ABCC) CCAD) ACA
  8. If DOG is coded as EPH (each letter +1), how is CAT coded?
    A) DBUB) DBTC) CBUD) DAU
  9. If YES is written as ZFT (each letter +1), how is NO written?
    A) OPB) OQC) MPD) NP
  10. If 🍎=Apple and 🍌=Banana, what does 🍎🍌🍎 spell?
    A) Apple Banana AppleB) Banana Apple BananaC) Apple Apple BananaD) Banana Banana Apple

Answer key

  1. A) EPH
  2. A) 🐱🐶
  3. A) B
  4. A) 5
  5. A) GVO
  6. A) RED BLUE
  7. A) CAC
  8. A) DBU
  9. A) OP
  10. A) Apple Banana Apple
